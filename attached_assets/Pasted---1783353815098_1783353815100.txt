اجعل صفحة "الملف الشخصي" احترافية بالكامل، وجميع العناصر تعمل فعلياً وليست مجرد تصميم.

المتطلبات:

1- بيانات المستخدم
- عرض الصورة الشخصية.
- الاسم.
- البريد الإلكتروني.
- تاريخ إنشاء الحساب.
- نوع الاشتراك (مجاني - PRO - PRO MAX).
- عدد المحادثات.
- عدد الصور التي تم إنشاؤها.
- آخر تسجيل دخول.

2- تعديل الملف الشخصي
- يستطيع المستخدم تغيير الصورة الشخصية.
- اختيار الصورة من معرض الهاتف.
- التقاط صورة بالكاميرا.
- قص الصورة قبل رفعها.
- ضغط الصورة تلقائياً.
- رفع الصورة إلى Storage.
- حفظ رابط الصورة في قاعدة البيانات.
- تحديث الصورة مباشرة في جميع صفحات التطبيق.

3- تعديل البيانات
- تعديل الاسم.
- تعديل اسم المستخدم.
- تعديل نبذة قصيرة.
- حفظ التعديلات مباشرة في قاعدة البيانات.
- التحقق من صحة البيانات قبل الحفظ.

4- لكل مستخدم بيانات مستقلة
- كل مستخدم يملك ملفه الشخصي الخاص.
- لا يمكن لأي مستخدم رؤية أو تعديل بيانات مستخدم آخر.
- يتم جلب البيانات حسب User ID الخاص بالمستخدم الحالي.

5- المحادثات
- لكل مستخدم محادثاته الخاصة فقط.
- عند إنشاء محادثة جديدة يتم ربطها بـ User ID.
- لا تظهر محادثات أي مستخدم آخر.
- عند حذف المحادثة يتم حذفها من حساب المستخدم فقط.

6- الصور
- كل الصور التي ينشئها المستخدم تحفظ في حسابه فقط.
- يستطيع عرضها وإعادة تحميلها وحذفها.

7- الإعدادات
- تغيير الاسم.
- تغيير الصورة.
- تغيير كلمة المرور.
- حذف الحساب.
- تسجيل الخروج.

8- حذف الحساب
- عند حذف الحساب يتم حذف:
  - الملف الشخصي.
  - جميع المحادثات.
  - جميع الصور.
  - جميع الملفات.
  - جميع بيانات المستخدم.
- مع نافذة تأكيد قبل الحذف.

9- الأمان
- استخدام Firebase Authentication أو نظام مصادقة آمن.
- استخدام User ID في جميع العمليات.
- منع الوصول إلى بيانات مستخدم آخر.
- تطبيق قواعد حماية قاعدة البيانات (Security Rules).

10- قاعدة البيانات
أنشئ Collections منظمة مثل:
- users
- chats
- messages
- generated_images
- subscriptions
- settings

كل سجل يجب أن يحتوي على userId ويتم جلب البيانات بناءً عليه فقط.

11- تجربة المستخدم
- جميع الأزرار تعمل فعلياً.
- جميع عمليات الحفظ والرفع تعمل.
- عرض رسالة نجاح أو فشل بعد كل عملية.
- وجود Loading أثناء الرفع أو الحفظ.
- تحديث البيانات فوراً بدون إعادة تشغيل التطبيق.

أريد تنفيذ كامل (Frontend + Backend) وليس مجرد تصميم أو عناصر وهمية، مع كود Production Ready، منظم، وآمن وقابل للتوسع.
